###Omniport

el proyecto consiste de una app enficada a la creacion musical que se conecta con tu DAW mandando señales midi en tiempo real para crear secuencias de acordes y arpegios. la idea es que la app funja como un instrumento virtual que se puede tocar con el mouse o con el teclado

al principio quise desarrollar un plugin pero devido a limitaciones de los vst decidi hacer una aplicacion stand alone con soporte midi para que se pueda conectar con cualquier DAW y con cualquier instrumento virtual.

###Funcionamiento 

la aplicacion esta con el stack comun para este tipo de proyectos en la industria y se maneja a traves de dos metodos la matriz y la placa de rasgueo 

###Objetivos

el proyecto en su face de MVP cumple con el objetivo de adaptar el workflow de el omnichord a cualquier instrumento virtual pero la idea es expandir esta logica a al proceso de creacion de una cancion desde 0 para que cualquier persona pueda componer una cancion ya sea sin tener conocimientos para hacerlo o por alguna discapacidad 

las funcionalidades planeadas son: 

-maquina de ritmos basica con 4 sonidos y secuenciador de patrones (16 pasos)

-creacion de melodias con el mousepad usando las notas de una tonalidad seleccionada 

-octavador para expandir el rango de notas y notas monofonicas para hacer bajos y meldias
